# Project 01: Mini Tensor Library

Build a small NumPy-backed tensor system to understand the abstractions underneath PyTorch.

## Scope

- Tensor storage
- Shape and strides
- Scalar and tensor arithmetic
- Broadcasting
- Matrix multiplication
- Views
- Reverse-mode automatic differentiation
- Gradient accumulation
- Computational graph traversal

## Milestones

1. Tensor data model
2. Shape and stride metadata
3. Elementwise operations
4. Broadcasting
5. Matrix multiplication
6. Autograd graph
7. Backward propagation
8. Tests and numerical gradient checks
9. Benchmarks against NumPy and PyTorch

## Engineering question

How much of a modern tensor framework can be reduced to storage, metadata, dispatch, and a graph of differentiable operations?
