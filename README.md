# Low-Level ML Engineering

A hands-on portfolio of machine learning systems projects, moving from tensor internals to GPU kernels, LLM inference, vLLM-style scheduling, and production serving.

## Projects

01. Mini Tensor Library
02. Autograd Engine
03. PyTorch C++ Operators
04. CUDA Kernel Lab
05. GPU Kernel Optimization
06. LLM Inference Engine
07. Mini vLLM
08. TensorFlow Internals
09. Model Serving Platform
10. ML Systems Benchmark Suite

Each project contains working code, tests, benchmarks, engineering notes, and reproducible experiments.

## Principles

- Build before documenting.
- Measure performance instead of guessing.
- Compare implementations against established frameworks.
- Keep each project independently runnable.
- Increase systems complexity progressively.
